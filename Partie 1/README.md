# Gestion d'un équipage

Ce programme permet de gérer un équipage.

## Fonctionnalités

- Ajouter un membre
- Retirer un membre
- Afficher l'équipage
- Vérifier si l'équipage est prêt
- Promouvoir un technicien
- Afficher un rapport
- Déclencher un événement aléatoire

## Lancer le programme

```bash
python crew.py
```
