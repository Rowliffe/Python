# TP2 - Fondation

Gestion d'un équipage de vaisseaux en programmation orientée objet.

## Fichiers

- `crew.py` : les classes `Person`, `Operator`, `Mentalist`, `Spaceship` et `Fleet`
- `main.py` : les tests des classes et des méthodes
- `menu.py` : le menu pour ajouter, retirer, afficher et vérifier l'équipage

## Lancer

Tests :

```
python main.py
```

Menu :

```
python menu.py
```
